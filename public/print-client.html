📱 Lakasir Mobile Print Bridge

Konfigurasi otomatis koneksi printer thermal Bluetooth/LAN untuk Android

⚙️ Parameter Koneksi

Gunakan IP LAN komputer kasir (contoh: http://192.168.1.10:8000). Jangan gunakan localhost jika membuka dari HP fisik.

Harus sama dengan PRINT_BRIDGE_TOKEN di file .env server.

📷 Scan QR / Buka di Android

Arahkan kamera HP atau gunakan tombol di bawah

🚀 Buka di Aplikasi Android ⬇️ Unduh APK Lakasir Bridge (Android)

Cara Penggunaan:

  1. Pasang aplikasi Lakasir Mobile Bridge di HP / Tablet Android kasir Anda (unduh APK di atas jika belum terpasang).
  2. Pastikan HP / Tablet terhubung ke jaringan Wi-Fi yang sama dengan komputer server kasir.
  3. Buka aplikasi Lakasir di Android, lalu scan QR Code di atas atau klik tombol Buka di Aplikasi Android.
  4. Pasangkan printer Bluetooth Anda pada Bluetooth Settings Android, lalu pilih printer pada tab Pengaturan di aplikasi Lakasir.
  5. Klik Mulai Polling Service untuk mode background, atau gunakan langsung tab POS untuk tampilan kasir layar penuh.
